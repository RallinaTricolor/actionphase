# Results Board: Game Setup

Game setup holds what the board needs for the whole game rather than one
phase. Open it with **Game setup** at the top right of any board, or with
**Results Board Setup** in the game's **⋯** menu. You can fill it in before
the first action phase starts: the codex and reward lists are often easiest
to write while you plan the game.

From a board, **Back to the board** returns you to the tab you were on.

## Sharing

**Share the results board** lets the audience watch every phase's board,
read-only, while the game runs. Once the game is in its epilogue or
completed, anyone who can see the game can. Viewers see everything on the
board, including your notes, private moments and codex secrets. It's off
until you turn it on. See [Audience](./audience#the-gm-s-results-board).

## Codex

The codex is the game's reference list. Each entry has a **type**: Location,
NPC, Item, Faction, Objective, Secret or Other. It also has a **name**, any
**other names** it goes by, and your **GM notes**.

What the board does with it:

- **Locations become the Map's rows.** Every card sits in a location, so add
  a phase's places before you start carding. Most phases have places of
  their own, so it's usually easiest to add them from that phase's
  [Map](./results-board-map#locations), which can also reuse an earlier
  phase's.
- **Names are highlighted** in submissions, and Read's sidebar shows what
  each submission mentions, with your notes.
- **Secrets are checked.** Tick **Secret** on any entry, and the checks
  before publishing warn when its name turns up in a result. **Allowed to
  know** lists the characters who may hear it.

**Applies to** decides which phases an entry belongs to: every phase, or the
ones you tick. A location is a row on the Map of each phase it applies to,
and no other. New locations and objectives start as one phase's (here, the
phase that's running, or the latest), and everything else as every phase's.
Change it in the add form before adding, or tick more phases afterwards.

**Show** narrows the list: everything, the every-phase entries, or one
phase's (its own entries plus the every-phase ones). With a phase shown,
new locations and objectives go to that phase, and an entry other phases
use too can be taken off it with **Remove from** that phase.

You can also add and edit entries from the board's own
[Codex tab](./results-board-codex-notes#codex), and from Read by selecting a
name in a submission.

::: tip The example
For *The Night Market*, the GM adds:

| Type | Name | Other names | Notes |
|---|---|---|---|
| Location | The Night Market | market, the stalls | |
| Location | Lantern Bridge | the bridge | |
| Location | The Gilded Cup | the Cup | A tavern by the river. |
| NPC | Captain Hale | Hale, the watch | Leads the night watch. |
| Item | The Ember Crown | the crown | |
| Secret | Forged crown | forgery, fake | **Allowed to know:** Jory Vance |

The three locations are for *The Night Market* only; Captain Hale, the crown
and the secret apply to every phase. The forgery is a secret only Jory knows. If Mara's result ever calls the
crown a fake, the checks before publishing will say so.
:::

## Character names

The names the board looks for when it matches a character in text: who a
submission names, who a result talks about, and whose name turns into "you".
By default each character has their full name and, if it's at least three
letters, their first name: **Mara Quill, Mara**.

Add nicknames and titles, comma separated. Matching uses the same capitals
you type. Leave a list empty to stop matching that character at all, which
helps when a first name is also an ordinary word.

::: tip The example
Sable signs her letters "Ott", so the GM makes her list
**Sable Ott, Sable, Ott**.
:::

## Writing results

**Moments read as "you"** is on by default. Each reader's copy of a scene
turns their own name into "you" and fixes the verb after it, and Write offers
**Make "you"** for drafts. Turn it off for a game written in the third
person. See [Scenes](./results-board-scenes#reads-as).
