# Results Board: Codex and Notes

The last two tabs on the board are reference material: the game's codex, and
your own notes.

## Codex

The same codex as on [Game setup](./results-board-setup#codex), opened from
the phase you're on.

- **The add form** is at the top: type, name, other names, and which phase
  it **applies to**. Locations and objectives start as this phase's; the
  rest start as every phase's. Pick another before adding if you need to.
- **The list** shows this phase's entries. **Show entries for other phases**
  shows the rest.
- **Edit** opens an entry in place: its type, name, other names, GM notes,
  which phases it applies to, and whether it's a secret (and who's allowed
  to know). An entry other phases use too has **Remove from "The Night
  Market"**, which takes it off this phase only; **Delete from every phase**
  removes it everywhere. Deleting shows a message with Undo. Deleting a location
  leaves its cards with no row; the Map gathers them under "No location"
  until you move them.

You don't have to leave a submission to add to the codex. In
[Read](./results-board-read#other-things-to-do-with-selected-text), select a
name and choose **+ Codex**: a small dialog opens with the name filled in.

## Notes

Two notes, side by side on a wide screen:

- **Notes for** this phase: plans, reminders, what the players are up to.
  Each phase's board has its own.
- **Notes for every phase:** the same note on every board in the game, for
  things like running threads and who owes whom.

Both use the same editor as posts and comments, with Write and Preview,
markdown help, and a handle to make the box taller. They save as you type.
Only you and your co-GMs can read them, unless you
[share the board](./results-board-setup#sharing).

::: tip The example
In the notes for every phase, the GM keeps a line for the forged crown: "The
real crown is still in Magister Vell's vault. Jory knows; nobody else does."
:::
