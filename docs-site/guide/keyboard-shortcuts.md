# Keyboard Shortcuts

Press `?` anywhere outside a text box to see this list in the app. On macOS, use `⌘` wherever this page says `Ctrl`.

## Anywhere (outside a text box)

| Keys | Action |
|------|--------|
| `?` | Show keyboard shortcuts |
| `n` | Jump to the next unread comment or message |
| `Shift` + `n` | Jump to the previous unread comment or message |
| `Esc` | Close a dialog or drawer |

`n` steps through the unread items currently on the page, top to bottom, and `Shift` + `n` steps back up. Both wrap around at the ends. In **manual read mode** it stops at comments you haven't marked as read. Unread comments in a collapsed thread, or on a page that hasn't loaded yet, are skipped.

Single-key shortcuts never fire while you're typing, so a `?`, `n` or `N` in a comment is just a character.

## In a text editor

| Keys | Action |
|------|--------|
| `Ctrl` + `Enter` | Send / submit — the same as clicking the form's send, post or save button |
| `Esc` | Cancel the reply or edit. If you've typed anything, you'll be asked before it's discarded |
| `Ctrl` + `B` | Bold |
| `Ctrl` + `I` | Italic |
| `Ctrl` + `K` | Link |

Closing a private-message reply box with `Esc` keeps your draft, so it doesn't ask.

## Mention and sheet-item suggestions

Typing `@` (characters) or `%%` (character sheet items) opens a suggestion list.

| Keys | Action |
|------|--------|
| `↑` / `↓` | Choose a suggestion |
| `Tab` or `Enter` | Insert the highlighted suggestion |
| `Esc` | Dismiss the suggestions |

While the list is open, `Tab` never moves you out of the text box, even when nothing matches. Press `Esc` first if you want to tab to the next control.
